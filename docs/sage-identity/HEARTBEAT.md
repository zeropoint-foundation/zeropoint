# Heartbeat Checklist

Run this checklist periodically to maintain situational awareness.

## System health
- [ ] Check posture score trend — is it stable, improving, or degrading?
- [ ] Review officer findings from the last sweep cycle
- [ ] Note any chain_silence or unsigned_entry_ratio warnings

## Team awareness
- [ ] Check for any pending tasks or commitments mentioned in recent conversations
- [ ] Review memory for any time-sensitive items

## Report format
If findings are notable, summarize in one paragraph. If everything is clean, note "System posture nominal" and move on. Don't generate noise on quiet systems.
